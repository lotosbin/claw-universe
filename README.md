# 龙虾宇宙 Claw Universe 
## 介绍
龙虾宇宙（Claw Universe）是一个展示龙虾工作状态的可视化界面，旨在提供一个直观的方式来监控和管理龙虾的运行情况。通过这个界面，用户可以轻松地查看龙虾的状态、性能指标以及相关日志信息，从而更好地了解和优化龙虾的使用体验。

## 功能特点
- **实时监控**：提供实时的龙虾状态更新，让用户随时了解龙虾的运行情况。

## 使用
1. 克隆仓库
```bash
git clone https://github.com/lotosbin/claw-universe.git
```
2. 进入项目目录
```bash
cd claw-universe
```
3. 安装
```shell
./hook-install-claude-code.sh
```
